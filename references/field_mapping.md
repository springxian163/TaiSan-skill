# 内蒙古泰三检验检测报告 → Excel 字段映射与提取规则

适用对象：**内蒙古泰三科技服务有限公司**出具的《检验检测报告》PDF（报告编号形如 `BG26xxxx`，封面/页眉编号 `TSKJ-JL-165`）。每月新增一份或多份，均为同一版式。

## PDF 版式速记
- **第 1 页（封面）**：左上角"报告编号：BG26xxxx"；中间列样品名称/型号规格/委托单位/检验类别；底部盖"内蒙古泰三科技服务有限公司检验检测专用章"，检测单位固定为"内蒙古泰三科技服务有限公司"。
- **第 2 页**：报告声明/说明，一般不取数。
- **第 3 页（信息表页）**：委托单位/样品名称/规格型号/生产单位/抽（送）样地点/抽（送）样人员/样品数量/检验检测结论 等。**该页字段是本技能的数据主源**。注意：泰三 PDF 是扫描件，无文本层，**必须渲染成图片后视觉读取**，不能用 `get_text()`。
- **后续页**：检测项目明细，每行"合格/不合格"，用于印证结论。

## Excel 列 ← PDF 字段映射
按 `工作AI表格.xlsx` 表头第 1 行列名取数：

| Excel 列 | 取值位置 | 说明 / 格式 |
|---|---|---|
| 序号 | 自动 | 自增文本，延续表内已有最大序号 |
| 采样地点 | **按"通知检测单位"反查映射表** | **不再从报告直读**。由 `通知检测单位`（即报告"抽（送）样地点"取出的公司名）查下方《通知检测单位 → 采样地点映射表》得到煤矿名；未命中则留空并在备注写"采样地点未匹配" |
| 取样人员 | 信息表"**检验检测人员**" | 原样照录（两人以空格分隔则照录，如"高欣禄 赵青梅"） |
| 供应站业务员/委托人 | 信息表"**送样人员**" | 原样照录，如"韩涛""张欣" |
| 样品供货商 | 信息表"生产单位" | 文本 |
| 型号及品牌 | 信息表"样品名称"+"规格型号" | 两者拼一起，中间空格 |
| 抽样数量 | 信息表"样品数量" | **原样照录**（常含单位，如"3根、4块、4个""15支""1片""2米"），不要换算成纯数字 |
| 取样时间 | 信息表"**样品接收日期**" | 泰三报告无"抽（送）样日期"，用"样品接收日期"代替（用户既定口径）；统一 `YYYY/MM/DD`（如 2026-04-15 → 2026/04/15），按文本存 |
| 报告编号 | 封面左上角 / 信息表页眉"报告编号" | 如 BG260078 |
| 检测报告状况 | 信息表"检验检测结论" | 只写**合格 / 不合格**：结论原文"所检项目符合……规定的技术要求"即判合格；明细页逐行均为合格 |
| 通知检测单位 | 信息表"抽（送）样地点" | 原样照录报告里的**公司全称**（不是煤矿名），例如"内蒙古仲泰能源集团有限公司伊旗分公司" |
| 检测单位 | **固定值** | **固定填"内蒙古泰三科技服务有限公司"**（用户指定，不再取报告落款） |
| 备注 | — | 记录识别不确定之处、缺字段"未找到"、采样地点未匹配等情况 |

## 铁律
1. **找不到的字段一律留空并在备注写"未找到"**，绝不推测或编造数值、日期、编号。
2. **数值/数量原样保留精度与单位**，不四舍五入、不换算单位（"3根、4块、4个"就照抄）。
3. 规格型号里的空格、符号（×、Φ、/）照抄，不做"清洗"。
4. 有歧义或不确定的判断，写进该行"备注"，不要静默替用户决定。
5. **采样地点只允许来自映射表反查，禁止从报告任何字段抄**；报告里如果直接写了煤矿名（极少数版式），仍以映射表反查结果为准。

## 常见易错点
- 泰三 PDF 是扫描件，**无文本层**，`get_text()` 取不到标签，必须走渲染→视觉读取。
- **供应站业务员/委托人取"送样人员"、取样人员取"检验检测人员"**（用户既定口径，勿与"委托单位联系人""抽（送）样人员"混用）。
- 少数旧版式报告无"送样人员/检验检测人员"字段，只有"抽（送）样人员"，按新口径两字段均"未找到"并备注，不套用旧的人名拆分规则。
- "取样时间"取自"样品接收日期"（泰三报告没有"抽（送）样日期"，这是用户明确指定的替代口径）。
- "抽样数量"列虽叫数值，但源值含单位，照抄原文，别硬拆成数字。
- **"通知检测单位"取报告"抽（送）样地点"的公司全称；"采样地点"由该公司全称查映射表反查得到煤矿名**——两者不再同值，反了会全错。
- 报告"抽（送）样地点"里的公司名若与映射表存在空格/换行/全半角差异，先做去空白、全半角统一再匹配；仍匹配不上就留空并在备注写"采样地点未匹配：<原公司名>"，不要硬猜。
- "检测单位"固定填"内蒙古泰三科技服务有限公司"，不随报告落款变化。
- 结论页若被红章遮挡，可结合明细页每行"合格/不合格"判定；全部合格→合格。
